# Python Practice Programs

## Overview

This repository contains Python practice programs created while learning the fundamentals of Python programming. The programs cover basic concepts and problem-solving exercises commonly used by beginners.

## Topics Covered

* Variables and Data Types
* Conditional Statements
* Loops
* Functions
* Lists
* Tuples
* Sets
* Dictionaries
* Basic Python Programs

## Sample Programs

* Voting Eligibility Check
* Largest Number Finder
* Divisibility Check
* Simple Decision-Making Programs
* List Operations
* Dictionary Operations

## Technologies Used

* Python 3
* Visual Studio Code (VS Code)

## Learning Outcomes

Through these programs, I practiced:

* Writing Python syntax correctly
* Implementing decision-making logic
* Using loops and functions
* Working with Python collections
* Solving basic programming problems
